# Lunar Archive — Forgotten on the Moon

Навчальний вебпрототип для проєкту SSU PCTE BTNA / NASA Space Apps Challenge. Сайт демонструє головний екран із п'ятьма інтерактивними картками приладів і сторінку з інформацією про кожен прилад.

## Структура проєкту

```text
lunar-archive/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── devices.js
│   └── main.js
├── images/
│   └── (сюди додавати фотографії приладів)
└── README.md
```

## Як запустити локально

1. Завантажте або розпакуйте репозиторій.
2. Відкрийте `index.html` у браузері.
3. Для локальної розробки можна відкрити папку у Visual Studio Code та скористатися розширенням Live Server.

Зовнішні бібліотеки та сервер для цього прототипу не потрібні.

## Як додати фотографії

1. Покладіть зображення у папку `images`, наприклад `device-1.jpg`.
2. Відкрийте `js/devices.js`.
3. У відповідному об'єкті вкажіть шлях до файлу:

```js
image: "images/device-1.jpg",
imageAlt: "Назва приладу на поверхні Місяця"
```

Підтримуються звичайні формати браузера: JPG/JPEG, PNG, WebP, SVG. Для GitHub краще використовувати оптимізовані зображення, щоб репозиторій не був надто великим.

## Як замінити тексти

Усі демонстраційні дані знаходяться в `js/devices.js`. Для кожного з п'яти приладів можна змінити:

- `title` — назва;
- `description` — опис;
- `year` — рік;
- `mission` — назва місії;
- `purpose` — призначення;
- `status` — статус;
- `image` — шлях до фото;
- `source` — посилання або назва джерела інформації.

Перевіряйте факти та використовуйте джерела NASA або інші надійні джерела. Дотримуйтеся умов використання та зазначайте авторство/джерело зображень.

## Публікація через GitHub Pages

1. Створіть новий публічний GitHub-репозиторій, наприклад `lunar-archive`.
2. Завантажте **вміст** цієї папки в корінь репозиторію: `index.html`, `css`, `js`, `images`, `README.md`.
3. Відкрийте репозиторій → **Settings** → **Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Через деякий час GitHub покаже адресу опублікованого сайту в цьому ж розділі.

## Поточний стан

Це початковий прототип. Назви й описи приладів поки демонстраційні, а фотографії потрібно додати після узгодження п'яти об'єктів дослідження.
